# 🌐 Consuming a REST API - My Learning Journey

This repository is dedicated to my learning process of consuming REST APIs using JavaScript (Fetch API, Promises, and Async/Await). It contains interactive HTML and JavaScript examples demonstrating HTTP requests to external services.

## 🚀 Goal
To master the fundamentals of API consumption, HTTP methods (GET, POST, PUT, DELETE), request query parameters, asynchronous JavaScript flow, and proper error handling.

---

## 📅 Progress Tracker

Here are the topics covered in this project and my current completion status:

- [x] **1. Basic HTTP Requests**
  - [x] GET: Fetching and rendering lists of resources.
  - [x] POST: Creating new resources with JSON payload.
  - [x] PUT: Updating existing resources.
  - [x] DELETE: Removing resources from the server.
- [x] **2. Advanced Fetching, Async/Await & Error Handling**
  - [x] Query Parameters: Filtering API request results (?userId=1).
  - [x] Async/Await: Modern syntax for handling asynchronous requests.
  - [x] Try/Catch: Robust error handling and HTTP status code validation.

## 🛠️ How to Run the Code

To run any of the HTML/JS examples locally, you don't need any complex setup, just a modern web browser.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/lukinhapdm/rest-api-learning.git
   ```

2. **Navigate to the repository directory:**
   ```bash
   cd basics
   ```

3. **Open an example in your browser:**
   Double-click any .html file (e.g., get.html, post.html, async-await.html) or open it directly in your preferred browser.
